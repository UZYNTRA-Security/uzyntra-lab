\section{Vulnerability Explanations}

\subsection{Workflow Vulnerabilities}
Business logic flaws arise when application functionality can be abused in ways not intended by developers. These cannot be detected by automated scanners — they require understanding the application's intended purpose.

\textbf{Examples:}
\begin{itemize}
  \item Applying a discount code multiple times
  \item Skipping steps in a checkout or registration flow
  \item Negative quantity in a cart (receive money instead of paying)
  \item Password reset without verifying email ownership
  \item Unlocking premium features by modifying response values
\end{itemize}

\subsection{Race Conditions}
Race conditions occur when two or more processes access shared data concurrently and the outcome depends on timing.

\textbf{Classic example:} Two simultaneous withdrawal requests both pass the balance check before either completes the deduction, allowing double-spending.
